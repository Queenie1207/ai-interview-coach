# AI Interview Coach Guidelines

- Use Next.js App Router, TypeScript, and Tailwind CSS.
- Do not use `any`.
- Run `npm run lint` and `npm run build` after changes.
- Keep components focused on a single responsibility.
- Keep mock data separate from UI components.
- Phase one must not add a backend, database, or AI API.
- Do not replace the technology stack or add large dependencies without a requirement.
